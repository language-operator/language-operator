## Prerequisites

Read:
- `requirements/personas/project-manager.md`
- `requirements/SCRATCH.md`

Adopt the project-manager persona.

## Directions

1. Use `gh` to view all open issues
2. Prioritize them in order of functional dependency
3. Label the top story as "ready" — if multiple issues can be done in parallel, label up to 3
4. No other stories should be labelled "ready"

Update `requirements/SCRATCH.md` if anything is worth remembering for the next run.

## Output

One to three GitHub issues with the "ready" label.
